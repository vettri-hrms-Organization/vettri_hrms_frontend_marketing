# Vettri Marketing — V3 Design Engineering Redesign

This version is a substantive homepage redesign built on the existing Vettri Next.js/TypeScript codebase.

## Design direction
- People + Workplace + Technology as the core product story
- Product-first visuals instead of feature-card repetition
- Premium enterprise navy/blue system
- Editorial typography and generous spacing
- Connected workflows as the main differentiator
- Responsive desktop/tablet/mobile behavior
- Reduced-motion support

## Verification
Run locally with:

```bash
npm install
npm run dev
```

Then verify production with:

```bash
npm run build
npm run start
```
