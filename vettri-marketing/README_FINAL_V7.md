# Vettri Marketing — Final V7 Design Pass

This version is the final art-direction pass over the existing Vettri marketing frontend.

## Design priorities
- Clear narrative order: product promise → connected system → product proof → lifecycle → automation → control → integrations → CTA.
- Premium visual hierarchy without excessive decoration.
- Product UI is the primary proof mechanism.
- Motion is restrained and purposeful.
- Responsive and reduced-motion behavior are included.

## Run
npm install
npm run dev

## Production check
npm run build
npm run start
