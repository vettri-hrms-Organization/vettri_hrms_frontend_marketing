# Vettri Marketing — Premium Product-Led V4

This version is the final presentation-focused redesign pass for the Vettri HRMS marketing website.

## What changed
- Product-led hero with a realistic Vettri command-center interface
- Clear People / Workplace / Technology positioning
- Connected-system brand section
- Realistic employee workspace preview
- Device operations console
- Employee lifecycle storytelling
- Workflow automation visualization
- Enterprise security/control console
- Integration ecosystem section
- Premium dark/light visual rhythm
- Responsive desktop/tablet/mobile layouts
- Reduced-motion support
- Preserved existing Next.js component architecture and routes

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production check

```bash
npm run build
npm run start
```
