# Vettri Marketing — Final Design Director Pass

This build is a restrained enterprise SaaS redesign focused on product credibility rather than decorative effects.

## Design intent
- Editorial typography and whitespace
- Realistic product UI as the primary visual proof
- People + Workplace + Technology as the product architecture
- Reduced card/grid repetition
- Controlled motion and shadows
- Enterprise-grade navy/blue palette
- Responsive layouts

## Run
npm install
npm run dev

## Production check
npm run build
npm run start
